# Электронная лаборатория

Локальное приложение для ПК: принципиальные схемы с реальными деталями, физически обоснованная симуляция (ngspice), виртуальные приборы и проектирование печатных плат для домашнего изготовления. Работает без интернета, без учётных записей и облака. Интерфейс на русском.

**Статус: версия 1.0.0 — проект завершён.** Этапы 1–6 приняты; 7–9 реализованы и ждут приёмки ([план](docs/PLAN.md), [итоговый отчёт](docs/reports/final.md), [руководство пользователя](docs/USER_GUIDE.md)). Есть всё основное из ТЗ: каталог реальных деталей и редактор микросхем, редактор схем с ERC, расчёт ngspice (рабочая точка, переходный процесс с воспроизведением, развёртка DC, АЧХ, параметрический прогон), проверка работы, приборы, печатная плата с DRC, заливкой, авторасстановкой и автотрассировкой (с перемычками), печать 1:1, Gerber/Excellon, G-code для CNC 3018 (GRBL), журнал испытаний и акт проверки для клиента.

## Как запустить (Windows, без установки)

1. Скачать `ElectronLab-1.0.0-win-x64-portable.zip`:
   - со страницы [Releases](../../releases) — архив прикрепляется автоматически, когда создан выпуск с меткой `v1.0.0` (Releases → Draft a new release → тег `v1.0.0` → Publish);
   - или артефакт «ElectronLab-win-x64-portable» последнего успешного запуска «Тесты» на вкладке Actions (хранится 30 дней);
   - или собрать самому: `npm run package:win`.
2. Распаковать в любую папку или на флешку.
3. Запустить `ElectronLab.exe`. Данные хранятся в папке `data` рядом с программой.

Перенос на другой ПК: скопировать папку целиком, либо «Экспорт проекта» / «Резервная копия всего» → на другом ПК «Импорт проекта» / «Восстановить резервную копию».

## Для разработки

```bash
npm install
npm start            # сборка и запуск
npm test             # все автотесты
npm run package:win  # портативный архив в release/
```
