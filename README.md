# Электронная лаборатория

Локальное приложение для ПК: принципиальные схемы с реальными деталями, физически обоснованная симуляция (ngspice), виртуальные приборы и проектирование печатных плат для домашнего изготовления. Работает без интернета, без учётных записей и облака. Интерфейс на русском.

**Статус: этапы 1–6 приняты; этапы 7, 7+, 8, 8а, 8б реализованы и ждут приёмки** ([план](docs/PLAN.md)). Есть всё основное из ТЗ: каталог реальных деталей и редактор микросхем, редактор схем с ERC, расчёт ngspice (рабочая точка, переходный процесс с воспроизведением, развёртка DC, АЧХ, параметрический прогон), приборы, печатная плата с DRC, заливкой, авторасстановкой и автотрассировкой, печать 1:1, Gerber/Excellon, G-code для CNC 3018 (GRBL), журнал испытаний.

## Как запустить (Windows, без установки)

1. Скачать `ElectronLab-<версия>-win-x64-portable.zip` — артефакт «ElectronLab-win-x64-portable» последнего успешного запуска GitHub Actions «Тесты» (вкладка Actions; нужен вход в GitHub, хранится 30 дней), либо собрать самому: `npm run package:win`.
2. Распаковать в любую папку или на флешку.
3. Запустить `ElectronLab.exe`. Данные хранятся в папке `data` рядом с программой.

Перенос на другой ПК: скопировать папку целиком, либо «Экспорт проекта» / «Резервная копия всего» → на другом ПК «Импорт проекта» / «Восстановить резервную копию».

## Для разработки

```bash
npm install
npm start            # сборка и запуск
npm test             # все автотесты
npm run package:win  # портативный архив в release/
```
