Этапы выполняются строго по порядку. Этап считается завершённым только после прохождения всех критериев приёмки и подтверждения пользователя. Статус обновляется в этом файле.

|---|---|---|

| 1b | Сквозной вертикальный прототип (раздел 10 ТЗ): R + C + источник → сохранение → netlist → расчёт ngspice → показания щупов → `.elab` → простая плата | **принят пользователем** ([отчёт](reports/stage-1b.md)) |
| 2 | Каталог реальных компонентов, редактор микросхем и корпусов, импорт из библиотек KiCad | **принят пользователем** ([отчёт](reports/stage-2.md), [ADR-0003](adr/0003-catalog-and-kicad-import.md)) |

| 8 | Полный цикл «схема → проверка → станок»: файлы G-code для CNC 3018 (GRBL), тест работоспособности, новые детали с моделями (реле, трансформатор, потенциометры, кварц, оптопара, логика КМОП, тиристоры…), свой корпус по координатам, авторасстановка и автотрассировка | **реализовано, автотесты зелёные; ожидает приёмки** ([отчёт](reports/stage-8.md)) |

> Порядок «1 → 1b»: раздел 12 ТЗ требует сначала полностью сделать этап 1, раздел 10 — сделать вертикальный прототип раньше расширения каталога. Прототип 1b берёт из этапов 2–6 только минимум (три встроенные детали, провода без редактора-полировки, один анализ, один прибор, одна односторонняя плата) и служит проверкой архитектуры. Порядок подтверждён пользователем 11.10.2026.

## Критерии готовности этапа 1

1. Приложение запускается, интерфейс на русском: вкладки «Схема», «Тест», «Плата», каталог слева, полотно в центре, свойства справа. Неготовые разделы явно помечены, без фиктивных данных.
2. Проекты: создать, переименовать, дублировать, удалить (в корзину), открыть.
3. Автосохранение с индикатором; восстановление после аварийного завершения; предупреждение о несохранённых изменениях при закрытии.
4. Undo/Redo (Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z) и контрольные версии (создать, список, восстановить).
5. Кнопки «Сохранить», «Сохранить как», «Экспорт проекта», «Импорт проекта», «Резервная копия всего», «Восстановить резервную копию».
6. `.elab` с manifest, контрольными суммами, версиями; отказ на повреждённых, подменённых, более новых файлах и файлах с повторяющимися ID; миграция старой версии.
7. Перенос: экспорт и бэкап из одной папки данных, импорт в чистую папку данных («второй ПК»), продолжение редактирования без потери данных.
8. Портативная сборка для Windows; данные в папке `data` рядом с программой.
9. Все автотесты (unit, integration, e2e) проходят; отчёт в `docs/reports/stage-1.md`.
10. Проверка на реальных Windows-ПК пользователем по чек-листу ADR-0001.

## Критерии готовности этапа 2

1. Экран «Каталог деталей» (с начального экрана и вкладкой в проекте): поиск по названию, партномеру, маркировке, корпусу и номиналу; категории; встроенные и мои детали; карточка с номиналами, пределами, обозначением, корпусами, выводами, моделью, источником.
2. Встроенный справочник: типовые R, C, L, предохранитель, варистор, разъёмы, кнопка, светодиод и распространённые реальные детали (диоды, стабилитроны, транзисторы, MOSFET, тиристор, симистор, NE555, LM358, LM317, L7805, 74HC00, ATmega328P) — помечены «не сверено».
3. Редактор деталей и микросхем: выводы с номерами, именами, типами и функциями; корпуса DIP/SOIC/SOP/TSSOP/QFP/QFN/BGA/SOT/TO/выводные/SMD с шагом, ключом первого вывода и нумерацией; несколько корпусов на партномер с явным соответствием «вывод ↔ площадка»; проверки дубликатов и пиновки, ошибки не дают сохранить.
4. Импорт из библиотек KiCad (официальные — по нажатию, или файлы с компьютера) с предпросмотром, источником и лицензией; сохраняется только после проверки пользователем; дальше работает без интернета.
5. SPICE-модель отдельно: описание выводов модель не создаёт; деталь без модели помечена, на схеме — предупреждение, расчёт честно отказывает.
6. Схема: размещение деталей из каталога; характеристики на схеме (номинал, напряжение конденсатора, партномер); «Добавить в мой каталог».
7. Своя деталь сохраняется, переживает перезапуск, входит в полный бэкап и в проект `.elab`; на другом ПК проект открывается с деталью, её можно добавить в каталог.
8. Формат проекта v3 с миграцией v2 → v3; все автотесты зелёные на Linux и Windows; отчёт `docs/reports/stage-2.md`.

## Критерии готовности этапа 3

1. Полотно: сетка с привязкой, масштаб колесом и кнопками, «показать всё», панорама правой кнопкой; выделение щелчком, Shift и рамкой; перемещение, поворот (R), отражение (X), копирование/вставка/дублирование (Ctrl+C/V/D), группы (Ctrl+G), удаление, правка параметров в панели свойств.
2. Провода с изгибами, ветвление от середины провода (узел с точкой), пересечение без контакта, свободные концы; метки цепей и питания (одно имя — одна цепь), земля.
3. Связность — граф в документе (формат v4 с миграцией v3 → v4); сети пересчитываются по графу, UUID сетей сохраняются.
4. Позиционные обозначения выдаются автоматически, ручное переименование с проверкой конфликтов, перенумерация по положению.
5. ERC: нет земли, неподключённые выводы, конфликт выходов, ошибочное питание, короткие соединения питания, несоответствие типов выводов — каждое замечание с местом, объяснением и уровнем; оговорка, что ERC не гарантирует замысел.
6. Экспорт SVG/PNG/PDF и печать: листы A4–A2, рамка и основная надпись, масштаб 1:1 / вписать, подписи; список соединений как общий интерфейс к расчёту и плате.
7. Проверки ТЗ: цепи с разветвлениями и пересечениями, перемещение детали без потери соединений, Undo/Redo, сохранение и перенос — автотестами через интерфейс; всё зелёное на Linux и Windows; отчёт `docs/reports/stage-3.md`.

## Критерии готовности этапа 4

1. Модели во встроенном справочнике: диоды, стабилитроны, светодиод, биполярные транзисторы, MOSFET, NE555, LM358, L7805, LM317 — с источником и отметкой «не проверена»; детали без модели и цифровые ИС честно не рассчитываются.
2. Своя SPICE-модель из даташита (.model или .subckt) подключается в редакторе детали с явным сопоставлением выводов; опасные директивы запрещены.
3. Анализы: рабочая точка, переходный процесс, развёртка DC, частотный (АЧХ/ФЧХ, частоты −3 дБ), параметрический прогон; настройки хранятся в проекте.
4. Источники сигналов: синус, прямоугольные импульсы, постоянный ток.
5. Токи выводов приборов и мощности; контроль пределов с указанием, где превышение.
6. Эталонные расчёты на ngspice сверены с формулами и даташитами; формат v5 с миграцией; все автотесты зелёные на Linux и Windows; отчёт `docs/reports/stage-4.md`.

## Критерии готовности этапа 5

1. Мультиметр с подвижными красным и чёрным щупами на выводах: V⎓, V~ (True RMS, частота, метод и окно измерения), A⎓ и A~ (амперметр включается последовательно в разрыв вывода, схема перестраивается), Ω, прозвонка, проверка диодов.
2. Ω, прозвонка, диод и ESR: питание схемы отключается, прибор подаёт свой ток или переменный сигнал; диапазоны и OL; показание зависит от нелинейных деталей так же, как у настоящего прибора.
3. Осциллограф: два канала, В/дел, смещение, время/дел, синхронизация (источник, фронт/спад, уровень, авто/ждущий), курсоры, автоизмерения.
4. ESR-метр: частота 100 Гц … 100 кГц, ESR, |Z|, ёмкость; зависит от модели конденсатора (электролит справочника — с параметром «ESR»).
5. Лабораторный блок питания: напряжение, ограничение тока, включение выхода; индикация CV/CC/OFF и показания выхода.
6. Все показания — из одного результата расчёта для текущей схемы или из измерения для текущей схемы и положения щупов; устаревшие показания не выводятся; неподдерживаемое — с объяснением, без выдуманных чисел.
7. Проверки ТЗ: делитель напряжения, RC-заряд, диод, источник с ограничением тока, осциллограмма, сравнение с эталоном — автотестами на ngspice и через интерфейс; всё зелёное на Linux и Windows; отчёт `docs/reports/stage-5.md`.

## Критерии готовности этапа 6

1. Плата: длина, ширина, единицы (мм/дюймы), односторонняя или двухсторонняя; правила — ширина дорожки, зазор, отступ от края, переходное отверстие, минимальное сверло и поясок; формат v6 с миграцией v5 → v6.
2. Перенос из схемы явной синхронизацией: отчёт «добавлено / удалено / изменено / проблемы» до применения; проверка соответствия выводов и площадок; разводка молча не удаляется, Ctrl+Z отменяет.
3. Расстановка: перемещение, поворот, перенос на другую сторону; ручная разводка с изгибами, переходные отверстия на двухсторонней плате; подсветка цепи и неразведённых соединений.
4. DRC: зазоры и короткие замыкания с точной геометрией, край платы, ширина дорожки, отверстия и поясок, слои, неразведённые цепи; переход к месту замечания.
5. Вывод 1:1: слой зеркально или нет с понятной подписью «для ЛУТ», калибровочный квадрат, SVG, PDF, печать; сборочный чертёж.
6. Gerber RS-274X и Excellon проверены независимым читателем: масштаб, площадки, отверстия, соответствие сетей.
7. Все автотесты зелёные на Linux и Windows; отчёт `docs/reports/stage-6.md`. Медные заливки — не в этом этапе (честно указано).

## Критерии готовности этапа 7

1. Журнал испытаний на каждую ревизию: название и дата, снимок ревизии схемы и платы, измеренное напряжение питания, приборы, условия, примечания, фото; формат v7 с миграцией v6 → v7 (прежние записи сохраняются).
2. Измерения в узлах и на деталях (напряжение, ток, сопротивление); сравнение с расчётом ревизии с учётом допусков деталей и погрешности прибора; значение без расчёта не выдумывается.
3. Отказы и замены деталей с обстоятельствами; гипотезы причин расхождений — только из фактов записи и схемы, с пометкой «не диагноз».
4. Изменение номинала, модели, схемы и разводки — обычными правками с историей (Undo/Redo, контрольные версии); сравнение ревизий; возврат старой ревизии без потери журнала.
5. Общий каталог не меняется по наблюдению: перенос детали из проекта в каталог — только с подтверждением.
6. Проверки ТЗ: отказ резистора, новый номинал, пересчёт, синхронизация платы, сравнение ревизий, возврат старой — автотестами через интерфейс; перенос журнала с фото на другой ПК; всё зелёное на Linux и Windows; отчёт `docs/reports/stage-7.md`.

## Критерии готовности доработок 7+

1. Новая плата любого размера (1–2000 мм, мм или дюймы) и формы: прямоугольник, скруглённые углы, круг, многоугольник по точкам; самопересекающийся контур не принимается; формат v8 с миграцией v7 → v8 (плата становится прямоугольной, заливок нет).
2. DRC, расстановка, печать 1:1, Gerber (Edge_Cuts) — по контуру платы.
3. Медная заливка цепи на слое: зазор не меньше общего, отступ от края, острова — предупреждение DRC; в Gerber — область с вырезами (полярность LPC), связность учитывается при подсчёте неразведённых соединений.
4. Деталь проекта меняется в проекте (не в общем каталоге), выводы с проводами и корпуса на плате защищены; правки номинала, детали, платы, заливки, синхронизации, возврата ревизии — в журнале изменений.
5. Примеры: светодиод, RC-фильтр, мультивибратор на NE555, стабилизатор LM317, заметки — открываются копией со стартового экрана, рассчитываются ngspice с проверкой результата в тестах.
6. E2E падают при любой ошибке в консоли окна; всё зелёное на Linux и Windows.
