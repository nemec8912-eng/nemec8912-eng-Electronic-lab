# Тесты

Все тесты входят в репозиторий и запускаются автоматически (GitHub Actions, `.github/workflows/tests.yml`) на **Linux и Windows**.

## Запуск

```bash
npm install
npm test                 # типы + unit + integration + e2e
npm run test:unit
npm run test:integration
npm run test:e2e         # собирает приложение и запускает окно Electron (на Linux без экрана — через xvfb-run)
npm run package:win      # портативный архив для Windows в release/
npm run package:linux
```

Проверка типов: `npm run typecheck` (полная, нужны `@types/*` из npm), `npm run typecheck:core` (строго: ядро, хранилище, тесты), `npm run typecheck:offline` (интерфейс по упрощённым объявлениям — для сред без npm).

E2E выполняются на экранах разного размера (проверено локально на 1024×768, 1280×720, 1600×1000; в CI на Windows экран раннера маленький). На 800×600 сценарии со схемой не проходят: они щёлкают по полотну в заданных точках, а при такой высоте окна эти точки попадают под строку состояния. Сама программа на 800×600 работает, это ограничение тестов.

## Что автотесты не покрывают

- Запуск на ПК пользователя с флешкой — чек-лист в [ADR-0001](adr/0001-desktop-shell-and-portability.md). Все наборы, включая e2e и портативный `.exe`, проходят в CI на `windows-latest` (Windows Server), но это не ваш компьютер.
- Внешний вид — проверяется глазами по скриншотам в отчёте этапа.
