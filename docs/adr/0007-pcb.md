# ADR-0007. Печатная плата: слои, разводка, DRC, вывод для изготовления

- Статус: **принято** (этап 6)
- Дата: 11.10.2026

## Контекст

ТЗ (раздел 8): режим «Плата» с размерами, единицами, числом слоёв (сначала односторонняя для домашнего изготовления, затем двухсторонняя), шириной дорожек, зазорами, отверстиями и площадками; перенос деталей и цепей из схемы с проверенным соответствием выводов; расстановка, поворот, ручная разводка, переходные отверстия, подсветка неразведённых цепей, DRC, границы платы, медные заливки — по мере реализации. Изменения схемы — только явной синхронизацией с отчётом, без молчаливого уничтожения разводки. Вывод: зеркальный и незеркальный, с понятной ориентацией стороны меди, печать 1:1 для ЛУТ, калибровочный квадрат, PDF/SVG; Gerber/Excellon — отдельная проверяемая функция, не объявлять готовой без тестов. Отдельные проверки масштаба, расстояний, отверстий и соответствия сетей. DRC не заменяет испытаний. Прототип 1b уже дал одностороннюю плату с прямыми дорожками между площадками.

## Решение

1. **Система координат.** Всё в мм, начало — левый верхний угол платы, вид со стороны деталей. Единицы (мм/дюймы) — только отображение и ввод; ввод понимает «1,6», «0,1″», «40 mil».
2. **Слои.** Односторонняя плата: медь только снизу; выводные детали сверху; SMD-детали при синхронизации ставятся снизу (со стороны меди). Двухсторонняя: медь сверху и снизу, переходные отверстия. Площадка выводной детали есть на обоих слоях, SMD — только на стороне детали. Деталь снизу видна сверху зеркально (по оси X корпуса), её можно перевернуть (F).
3. **Дорожка** — ломаная на одном слое между двумя концами; конец — площадка или переходное отверстие (формат v6). Дорожка допускается только между концами одной цепи схемы и только на слое, где есть медь обоих концов. Трасса с переходами («дорожка → переход → дорожка на другом слое») создаётся одной правкой. При перемещении и повороте детали концы следуют за площадками, изгибы сохраняются. Ветвление — несколькими дорожками от площадки или перехода.
4. **Связность** считается по верным дорожкам (ошибочные — ставшие «чужими» после правки схемы, на неверном слое — не соединяют). Неразведённые соединения — ближайшие пары между уже соединёнными группами площадок цепи; в DRC — по цепям с именами.
5. **Геометрия и DRC.** Медь — фигуры: круглая площадка и переход — точка с радиусом, овальная — отрезок с радиусом, прямоугольная — многоугольник, отрезок дорожки — капсула. Расстояние между фигурами считается точно, а не по описанной окружности. DRC проверяет:
   - зазоры между медью разных цепей на общем слое и касание (короткое замыкание);
   - отступ от края;
   - минимальную ширину дорожки, минимальное сверло, поясок меди, расстояние между отверстиями;
   - дорожки между разными цепями, на неверном слое, на верхнем слое односторонней платы; SMD на стороне без меди; переходы на односторонней плате;
   - детали, удалённые из схемы, перекрытие корпусов и корпус за краем — предупреждения;
   - неразведённые цепи.

   Каждое замечание указывает место и объекты — щелчок в списке показывает их на плате.
6. **Правила по умолчанию** — для ЛУТ и фоторезиста: дорожка 0,8 мм (минимум 0,4), зазор 0,4 мм, край 0,5 мм, переход 0,8/1,6 мм, минимальное сверло 0,5 мм, поясок 0,25 мм. Правила хранятся в плате (формат v6).
7. **Синхронизация** сначала строит отчёт, применяет его только кнопка «Применить» (отменяется Ctrl+Z). Отчёт перечисляет:
   - добавленные детали — их ставят на свободное место платы, а не поместившиеся — под платой с отметкой;
   - удалённые детали и число их дорожек;
   - изменённые детали — при смене корпуса место и поворот сохраняются, дорожки к сохранившимся площадкам остаются;
   - выводы, подключённые на схеме, но не сопоставленные площадке;
   - дорожки и переходы, ставшие «чужими». Такие дорожки не удаляются, их показывают отчёт и DRC.
8. **Ориентация вывода для ЛУТ.** Рисунок слоя печатается 1:1 (SVG с размерами в мм, PDF того же размера, печать). При переносе тонера изображение зеркалится, поэтому нижний слой для ЛУТ печатается без зеркала, а верхний — зеркально; программа выбирает это сама. Подпись на поле листа называет слой, зеркало и «для ЛУТ / НЕ для ЛУТ»; рядом — квадрат 10 × 10 мм для проверки масштаба и керны в центрах отверстий. Отдельно выводится сборочный чертёж.
9. **Gerber и Excellon.** Архив `.zip` содержит:
   - медь (`F_Cu`, `B_Cu`), маску (открыты площадки +0,05 мм на сторону, переходы закрыты), шелкографию (контуры корпусов), контур платы — Gerber RS-274X с атрибутами X2, мм, формат 4.6, начало в левом нижнем углу;
   - сверловку Excellon в мм с десятичными координатами;
   - `readme.txt`.

   Имена файлов — латиница. Если в DRC есть ошибки, программа перед сохранением спрашивает подтверждение. В readme и в интерфейсе сказано: экспорт проверен автотестами, а не производителем.

## Проверка

- Экспорт проверяет **независимый читатель** (`tests/gerber-reader.ts`). Он написан по спецификации Gerber/Excellon без кода экспорта. Он разбирает файлы и растеризует медь с шагом 0,02 мм, затем находит связные области с учётом металлизированных отверстий.
- Сравнение с платой (`tests/integration/pcb-export.test.ts`):
  - контур 50 × 40 мм;
  - каждая площадка на своём месте и своего размера, маска шире на 0,05 мм;
  - суммарная длина и ширина дорожек;
  - отверстия и их диаметры;
  - **цепи**: площадки одной цепи — одна область меди, разные цепи не касаются. Неразведённая цепь разорвана и в Gerber. На двухсторонней плате GND собрана через переход, а без металлизации перехода распадается на две части. Короткое замыкание, найденное DRC, видно и в растре.
- Unit-тесты: геометрия расстояний, DRC с точными числами (зазор 0,3 мм — ошибка, 0,5 мм — нет; разные слои не мешают), синхронизация (удаление, смена корпуса, несопоставленный вывод, SMD снизу), миграция v5 → v6.
- E2E: разводка с изгибами через интерфейс, DRC 0/0, SVG 75 × 58 мм, PDF MediaBox 212,6 × 164,4 пункта, Gerber из архива, двухсторонняя плата с переходом, запрет вернуть одностороннюю, зеркало верхнего слоя.

## Не сделано (честно)

Медные заливки (полигоны с зазорами) не реализованы — в ТЗ они «по мере реализации». Нет автотрассировщика, дуг и скруглений, текста в меди и шелкографии (позиционные обозначения есть только на сборочном чертеже), перемычек для односторонней платы, термобарьеров, вырезов и платы непрямоугольной формы.
