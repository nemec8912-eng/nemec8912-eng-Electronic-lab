# ADR-0010. Детали по типу и корпусу, карточка детали на схеме

- Статус: **принято** (ТЗ пользователя от 12.10.2026, «новый принцип каталога»)
- Дата: 12.10.2026

## Контекст

Пользователь не хочет искать готовую деталь с нужным номиналом. Нужно: каталог → тип → корпус → деталь под
курсором → щелчок → двойной щелчок → карточка → ввести характеристики → «Сохранить». Изменения касаются
только выбранной детали, каталог реальных деталей и SPICE-модели остаются, формат и старые проекты не ломаются.
Программа не должна придумывать распиновку: корпус TO-220 не говорит, какой транзистор в нём стоит.

## Решение

1. **Шаблоны «тип + корпус» — обычные детали встроенного справочника** (`origin.source` = «шаблон…»),
   сгруппированные `partTemplates()`: резисторы (выводные, 0402…2512), конденсаторы (керамические,
   плёночные, электролитические), катушки, диоды (DO-41/35/201, SMA/B/C), светодиоды, стабилитроны,
   транзисторы и тиристоры (TO-92, TO-220, TO-247, SOT-23), микросхемы (DIP, SOIC, SOP, TSSOP, QFP, QFN,
   BGA), варисторы, разъёмы, кнопки и «другие». Прежние типовые детали служат шаблонами со своими id —
   проекты, где они уже стоят, не меняются. Новое семейство корпусов — TO-247.
2. **Формат не меняется.** Номиналы — у экземпляра (`instance.values`, как и раньше); маркировка, пределы,
   допуск, модель, корпус и назначение выводов — у детали проекта. Карточка, меняющая деталь, которой
   пользуются и другие экземпляры, сначала **ответвляет** её (копия детали со своим id; символ, корпуса и
   модели — общие). Поэтому правка R1 не меняет R2, а новый резистор из того же шаблона получает исходные
   характеристики.
3. **Распиновка не придумывается.** У шаблонов транзисторов, тиристоров, симисторов соответствие
   «вывод ↔ площадка» пустое; проверка детали — предупреждение, DRC платы — ошибка «выводы корпуса не
   назначены». Назначить можно вручную в карточке или взять из справочника по маркировке (модель и выводы,
   если у детали справочника такой же корпус; распиновка справочника «не сверена» — предупреждение).
   У пассивных и микросхем соответствие «номер вывода = номер площадки» — это определение, а не догадка;
   у диодов вывод 1 корпуса — катод (полоса).
4. **Модель не выдумывается.** У шаблонов диодов, транзисторов и микросхем модели нет; расчёт честно
   отказывает, пока пользователь не выберет модель из справочника. Типовые модели с параметрами на схеме
   есть там, где поведение определяется самим номиналом (R, C, L, L + сопротивление обмотки,
   стабилитрон с заданным напряжением, варистор, реле — из ADR этапа 8).
5. **Ввод величин**: «10 Ом», «4,7 кОм», «4k7», «10k», «1M», «4700», «47 мкФ», «47uF», «100nF», «220pF»;
   неверное — сообщение по-русски с примерами, карточка не закрывается.
6. **Размещение**: выбранная деталь рисуется полупрозрачно под курсором, ставится щелчком, Esc — отмена.
   Двойной щелчок по детали (не по выводу) открывает карточку; одиночный — выделение, как раньше.

## Последствия

- Одна правка карточки — одна запись истории (Ctrl+Z) и одна строка журнала изменений.
- При смене корпуса или выводов у детали, стоящей на плате, карточка предупреждает; дорожки не удаляются
  молча — изменения приходят на плату через синхронизацию с отчётом.
- Неиспользуемые после ответвления символы, корпуса и модели остаются в библиотеке проекта (на них могут
  ссылаться контрольные версии).
