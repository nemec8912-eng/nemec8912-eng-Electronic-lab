# ADR-0011. Проволочные перемычки на односторонней плате

- Статус: **принято** (пользователь, 13.10.2026: «односторонняя плата — можно допускать перемычки на одной стороне»)
- Дата: 13.10.2026

## Контекст

Плотные схемы (пример «Металлоискатель»: две DIP-14, подстроечник, пьезоизлучатель) на односторонней плате
дорожками не разводятся. Двухсторонняя плата на CNC 3018 — две установки заготовки и реперные отверстия;
любители чаще ставят на односторонней плате несколько проволочных перемычек со стороны деталей.

## Решение

1. **Модель (формат v10).** `pcb.jumpers[] = { id, netId, aViaId, bViaId }` — провод между двумя
   отверстиями. Отверстия — обычные записи `pcb.vias` (сверло 0,8 мм, площадка 1,8 мм), поэтому дорожки
   подходят к ним как к переходу (`{kind:'via'}`), а связность, сверловка, медь, заливка и станок их
   уже понимают. Ссылки названы `…Id`, чтобы их переназначало копирование проекта (UUID). Миграция
   v9 → v10 добавляет пустой список.
2. **Одна правда о слоях.** `viaLayers(doc)`: на двухсторонней плате отверстие — медь обоих слоёв,
   на односторонней — только низ. `boardVias(doc)`: на односторонней плате в медь, сверловку, Gerber,
   заливку и G-code идут только концы перемычек; «просто переход» на односторонней плате остаётся ошибкой DRC.
3. **Связность.** Перемычка соединяет свои отверстия (`copperGroups`), если оба на месте и той же цепи.
4. **DRC.** Перемычка короче 2,54 мм — ошибка (провод не согнуть); пересечение с перемычкой другой
   цепи и провод ближе 0,5 мм к выводу детали другой цепи — «короткое замыкание» (провод голый и лежит
   со стороны деталей, где торчат выводы); отверстие под корпусом — предупреждение (паять до установки
   детали); на двухсторонней плате провод поверх меди верхнего слоя — предупреждение.
5. **Автотрассировка.** Сначала одна попытка без перемычек. Если на односторонней плате что-то не
   развелось, — попытки, где поиск пути может «перепрыгнуть» прямой перемычкой по горизонтали или вертикали
   длиной кратной 2,54 мм (до 25 мм). Перемычка дорогая (60 шагов сетки), её провод занимает «слой
   перемычек» в согласованной трассировке, отверстия — места на меди. Из результатов выбирается тот,
   где меньше неразведённых, затем меньше перемычек, затем короче дорожки.
6. **Вручную.** При прокладке дорожки на односторонней плате J (или кнопка «Перемычка») ставит первое
   отверстие, щелчок — второе, дальше снова дорожка. Удаление любого отверстия перемычки удаляет её
   целиком вместе с подходящими дорожками.
7. **Вывод.** Gerber: отверстия в сверловке, площадки на нижнем слое, маска над ними открыта, линия
   перемычки на шелкографии; сборочный чертёж — «П1 17,78 мм»; ПРОЧТИ.txt для станка — список перемычек
   с длинами и координатами.

## Последствия

- Старые проекты открываются без изменений (перемычек нет).
- Двухсторонняя плата ↔ односторонняя: отверстия перемычек не мешают смене (это не переходы).
- Автотрассировка на плотной односторонней плате дольше (неудачная попытка без перемычек), на примере
  «Металлоискатель» — около 20 с.
