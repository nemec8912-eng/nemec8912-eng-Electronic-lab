# Отчёт: доработки 8в (14.10.2026)

Закрыты два пункта ТЗ, которые оставались не сделанными после этапов 4 и 2.

## Реализовано

- **Воспроизведение переходного процесса** (ТЗ, раздел 6: «Пауза/Остановить», скорость, шаг по времени). Вкладка «Тест» → правая панель «Воспроизведение»:
  - «Воспроизвести», «Пауза», «Стоп» (в начало записи), шаг на точку расчёта вперёд и назад, ползунок времени;
  - скорость ×0,1 … ×4; при ×1 весь расчёт проигрывается за 10 с, рядом подпись «1 с на экране = … схемы»;
  - на графике под схемой — отметка текущего момента;
  - момент, номер точки расчёта и пометка «между точками — интерполяция», если момент не совпадает с точкой ngspice.
- **Индикаторы на схеме** (только по рассчитанным значениям, с легендой):
  - напряжения узлов — в текущий момент воспроизведения (в рабочей точке — как раньше);
  - цвет провода по потенциалу: серый — 0 В, красный — максимум, синий — минимум за расчёт; шкала не «прыгает» при воспроизведении;
  - стрелки направления условного тока с подписью величины, толщина — по току (логарифмически). В легенде сказано, что это условный ток, а не движение электронов. Токи меньше 1 нА не показываются (направление не определено);
  - переключатель «Токи и напряжения на схеме».
- **Диодный мост рассчитывается.** Раньше «Диодный мост (типовой)» был без модели, расчёт честно отказывал. Теперь — модель из четырёх диодов с параметрами 1N4007 (помечена «не проверена»). Корпус по-прежнему не задан: разводка выводов у мостов разных серий разная.

## Ограничения

- Между точками расчёта значения интерполируются линейно; так и подписано. Точность — как у шага расчёта ngspice.
- Стрелки — у деталей (вдоль детали или у вывода микросхемы), не вдоль каждого провода.
- Анимация штриха стрелки — только знак направления; при системной настройке «уменьшить движение» она отключается.
- Модель моста упрощённая: без теплового режима, импульсного тока и разброса диодов.
